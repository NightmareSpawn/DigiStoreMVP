# دیجی‌استور MVP

فروشگاه آنلاین با Next.js 14 + TypeScript + Prisma — نسخه MVP با پنل ادمین چندسطحی، احراز هویت موبایل، پرداخت کارت‌به‌کارت و زرین‌پال (sandbox).

> ⚠️ این نسخه هنوز روی هیچ ماشینی اجرا نشده (به‌خاطر محدودیت شبکه سندباکسی که کد توش نوشته شد). کد از نظر ساختاری بررسی شده ولی ممکنه در اولین اجرا به ۱-۲ باگ کوچیک بربخورید — طبیعیه.

## این پروژه چی داره و چی نداره

**داره:**
- فروشگاه با ۴ نوع محصول (فیزیکی، فایل دانلودی، ویدئوی آموزشی، خدمات)
- ثبت‌نام/ورود با موبایل + کد تأیید پیامکی (OTP) + کد دعوت + کد معرف
- سبد خرید، چک‌اوت، پرداخت کارت‌به‌کارت و زرین‌پال (sandbox — بدون نیاز به مجوز واقعی برای تست)
- پنل ادمین: سوپر ادمین (دسترسی کامل) + ادمین محدود (فقط دسته‌بندی‌های تخصیص‌یافته)
- مدیریت محصول، قیمت (خط‌خورده/نهایی/تمام‌شده)، تخفیف تکی و گروهی، تاریخچه قیمت
- کدهای تخفیف، سطح‌بندی خودکار مشتری (برنز/سیلور/رزگلد/گلد بر اساس مبلغ خرید)
- ثبت نظر محصول (فقط خریداران تأییدشده)، مقایسه تا ۵ محصول
- محدودیت "خرید فقط با موبایل اختصاصی" برای دسته‌بندی‌های خاص (آماده برای اتصال به شاهکار)

**نداره (نیاز به مجوز/قرارداد رسمی دارن، در این فاز پیاده نشدن):**
- اتصال زنده به دیجی‌کالا، ترب، ای‌مالز
- احراز هویت واقعی شاهکار (فعلاً mock — همیشه تأیید می‌کنه)
- درگاه زرین‌پال واقعی (فعلاً sandbox)
- اینماد
- ارسال پیامک واقعی (فعلاً کد OTP در کنسول سرور چاپ می‌شه)
- بخش آموزش، سئوی کامل

هرجای کد که باید بعداً به سرویس واقعی وصل بشه، با کامنت `MOCK` یا توضیح مشخص شده (مخصوصاً در `src/lib/otp.ts`, `src/lib/shahkar.ts`, `src/lib/zarinpal.ts`, `src/lib/marketPrices.ts`).

## روش ۱: اجرا روی لپ‌تاپ خودتون (ویندوز)

### پیش‌نیاز: نصب Node.js

۱. برید به [nodejs.org](https://nodejs.org) و نسخه **LTS** رو دانلود و نصب کنید (نسخه ۲۰ یا بالاتر).
۲. برای اطمینان، یک پنجره PowerPoint... ببخشید PowerShell باز کنید و بزنید:
   ```
   node -v
   npm -v
   ```
   اگه عدد نشون داد، نصب درست بوده.

### مراحل اجرا

۱. پروژه رو از گیت‌هاب دانلود کنید (یا `git clone` بزنید، یا از گیت‌هاب دکمه Code → Download ZIP رو بزنید و اکسترکت کنید).

۲. در PowerShell برید داخل پوشه پروژه:
   ```
   cd C:\Users\user\Downloads\DigiStoreMVP
   ```

۳. نصب پکیج‌ها (ممکنه چند دقیقه طول بکشه):
   ```
   npm install
   ```

۴. فایل تنظیمات محیطی رو بسازید — فایل `.env.example` رو کپی کنید و اسمش رو بذارید `.env`:
   ```
   copy .env.example .env
   ```
   (مقادیر پیش‌فرض برای تست کافیه، نیازی به تغییر نیست.)

۵. دیتابیس رو بسازید (SQLite — فایلیه، نیازی به نصب جداگانه نداره):
   ```
   npx prisma db push
   ```

۶. داده‌های نمونه (چند محصول، یک سوپر ادمین، کد دعوت) رو وارد کنید:
   ```
   npm run db:seed
   ```
   خروجی یک شماره موبایل سوپر ادمین و کد دعوت `WELCOME` رو نشون می‌ده — یادداشت کنید.

۷. سرور رو بالا بیارید:
   ```
   npm run dev
   ```

۸. مرورگر رو باز کنید: **http://localhost:3000**

### تست کردن

- برای **ثبت‌نام مشتری عادی**: روی "ورود/ثبت‌نام" بزنید، یک شماره موبایل دلخواه (مثلاً `09120000001`) و کد دعوت `WELCOME` رو وارد کنید. کد تأیید ۶ رقمی رو **در همون ترمینالی که `npm run dev` توش اجراست** می‌بینید (چون هنوز به سرویس پیامک واقعی وصل نیست).
- برای **ورود به پنل ادمین**: با همون شماره‌ای که مرحله ۶ (seed) بهتون داد وارد بشید (کد تأییدش هم توی ترمینال چاپ می‌شه) — مستقیم به `/admin` هدایت می‌شید.

## روش ۲: اجرا در فضای ابری رایگان (بدون نیاز به نصب چیزی روی لپ‌تاپ)

اگه لپ‌تاپتون ضعیفه یا نمی‌خواید چیزی نصب کنید، از **GitHub Codespaces** استفاده کنید — یک VS Code کامل توی مرورگر، با حساب گیت‌هاب رایگان.

۱. برید به ریپوی پروژه روی گیت‌هاب.
۲. دکمه سبز **Code** رو بزنید → تب **Codespaces** → **Create codespace on main**.
۳. چند دقیقه صبر کنید تا محیط بالا بیاد (یک VS Code کامل توی مرورگرتون باز می‌شه، با ترمینال).
۴. توی ترمینال همون دستورات بالا رو بزنید (مراحل ۳ تا ۷ بالا — `npm install`، کپی `.env`، `prisma db push`، `db:seed`، `npm run dev`).
۵. وقتی سرور بالا اومد، Codespaces یک پاپ‌آپ "Open in Browser" نشون می‌ده روی پورت ۳۰۰۰ — همونجا سایت رو می‌بینید.

> حساب‌های گیت‌هاب رایگان ماهیانه ~۶۰ ساعت Codespaces رایگان دارن — برای توسعه و تست این پروژه کافیه.

## دیپلوی روی اینترنت واقعی (وقتی آماده نمایش به بقیه بودید)

برای دیپلوی رایگان و سریع:
1. یک دیتابیس Postgres رایگان از [neon.tech](https://neon.tech) بسازید (SQLite برای پروڈاکشن مناسب نیست چون روی هاست‌های سرورلس فایلش پاک می‌شه).
2. در `prisma/schema.prisma` خط `provider = "sqlite"` رو به `provider = "postgresql"` تغییر بدید.
3. پروژه رو به [vercel.com](https://vercel.com) وصل کنید (مستقیم از گیت‌هاب، چند کلیک) و متغیرهای محیطی `.env` رو اونجا وارد کنید.

## ساختار پروژه (خلاصه)

```
prisma/schema.prisma       همه مدل‌های دیتابیس (کاربر، محصول، سفارش، پرداخت، ...)
prisma/seed.ts             داده‌های نمونه اولیه
src/lib/                   منطق مشترک (auth, otp, zarinpal, permissions, ...)
src/app/                   صفحات و API routes (ساختار Next.js App Router)
src/app/admin/             پنل ادمین
src/app/api/                API routeها (بک‌اند)
src/components/            کامپوننت‌های React قابل‌استفاده‌مجدد
```

## مشکلی پیش اومد؟

اگه موقع `npm install` یا `npm run dev` خطا دیدید، متن خطا رو برام بفرستید تا کمک کنم دیباگش کنیم — چون این اولین باری‌ه که این کد واقعاً روی یک ماشین واقعی اجرا می‌شه.
